Agents Deck Privacy Terms

Get Agents Deck

Agents Deck shows the Claude Code and Codex sessions running on your computer, on your phone or in a browser.

The pairing code lasts two minutes. If it has run out, show a new one in Settings › Connections › Mobile on your computer.

Use in this browser Open in app

On iPhone or iPad, add Agents Deck to your Home Screen first: open the web app in Safari, tap Share, then Add to Home Screen. Open it from the Home Screen and choose Paste pairing link. The installed app does not share Safari's storage, so the pairing has to happen inside it.

If Open in app does nothing, update the app.

The web app works over your Tailscale network only; it needs Browser access turned on in the same settings page.

Download for Android · All releases

This code does not pair a browser: the computer's Browser access is off or was not offered when the code was made. The Android app pairs with it.
