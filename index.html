Agents Deck

Claude Code and Codex control panel for your JetBrains IDE.

Agents Deck is the control panel around a coding agent, not another chat box: browse every session across every project, diff what the agent changed against the pre-session file and revert what you don't want, watch token use and cost per day, model and project, and schedule runs. It works with the claude and codex command-line tools you already have installed.

What it does

  • Sessions — work across projects with duration, model and estimated cost; resume in chat or the terminal.
  • Review — compare changed files with their pre-session versions, revert per file.
  • Usage — tokens and estimated cost by day, model or project, with plan limits.
  • Chats — file mentions, pasted images, MCP servers, skills and subagents.
  • Scheduled runs — queue prompts and pick them up after a restart.

Local session browsing and review

Agents Deck reads the files the agent CLIs already write on your computer. Local browsing and diff review do not send your code or prompts to us. Optional IDE diagnostic reports use JetBrains Marketplace Exception Analyzer and can be shared with the plugin developer under the IDE's reporting consent and settings. The Privacy Policy describes these reports and the other features that send data to external services.

Install

Agents Deck is not on JetBrains Marketplace yet. Requires a JetBrains IDE on build 253 (2025.3) or newer, and your own installation of Claude Code or Codex.

Extensions

Optional integrations ship as separate plugins, one repository each, and install from Settings › Tools › Agents Deck › Connections › Extensions: Linear, Sentry, Granola and Tessl. There is also an Android companion app for the optional mobile bridge.
